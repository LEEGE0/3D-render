# 01. 프로젝트 개요

## 목적

이 프로젝트는 DARK SOULS REMASTERED PvP 상황을 3D로 재현하고 설명 영상을 만드는 Windows 11 전용 오프라인 편집기다. 사용자가 전투 영상을 직접 3D로 모델링하는 부담을 줄이고, 위치·방향·타이밍과 판정 관계를 교육 자료로 명확히 보여주는 것이 핵심이다.

일반 3D 편집기처럼 모델링, 리깅, 재질 제작 전체를 제공하지 않는다. PvP 교육에 반복해서 필요한 장면 배치, 키프레임, 이동 경로, 락온, 공격 표시, 뒤잡 분석, 카메라와 영상 출력에 집중한다.

## 해결하려는 문제

실제 게임 영상만으로는 다음 내용을 정지 화면이나 말로 정확히 설명하기 어렵다.

- 여러 플레이어가 시간에 따라 어디로 이동했는가
- 각 순간 누구를 바라보고 있었는가
- 공격이 시작될 때 상대 후방과 공격 방향의 관계가 어땠는가
- 락온 이동과 자유 방향 이동이 어떻게 다른가
- 특정 전술에서 아군과 침입자의 간격이 어떻게 변했는가
- 뒤잡 성공·실패를 교육용 기준으로 어떻게 시각화할 것인가

편집기는 이 정보를 동일한 장면 데이터로 기록하고 탑뷰, 3D, 텍스트 가이드, 영상으로 재사용한다.

## 사용자 작업 방식

### 자동 가져오기

기존 `gangqueen-topview-guide-v1` 같은 좌표 파일을 불러와 캐릭터, 시간, 위치, 방향, 락온과 행동 키프레임을 자동 생성한다.

### 직접 제작

빈 장면에 캐릭터를 추가하고 탑뷰 또는 3D에서 이동·회전한 뒤 키프레임과 행동을 기록한다.

### 혼합 편집

좌표 파일을 불러온 다음 궤적, 타이밍, 행동, 카메라와 설명 오버레이를 수정한다. 실제 사용에서 가장 중요한 흐름이다.

## 성공 기준

첫 실용 버전은 다음 시나리오를 처음부터 끝까지 수행할 수 있어야 한다.

1. `가이드\전략1\scene.json`을 불러온다.
2. 네 캐릭터와 네 개 키프레임이 탑뷰와 3D에 동일하게 나타난다.
3. 한 캐릭터를 탑뷰에서 옮기면 3D와 속성 패널이 즉시 갱신된다.
4. 락온 상태에서 이동할 때 대상 방향으로 Yaw가 자동 계산된다.
5. 공격 키프레임에서 공격 표시와 뒤잡 판정 오버레이가 나타난다.
6. 타임라인을 재생해 위치와 방향이 끊기지 않고 보간된다.
7. 수정된 장면을 저장하고 다시 열어 같은 결과를 얻는다.
8. 지정 구간을 일정한 FPS의 영상으로 출력한다.

## 제품 원칙

- 정확성 우선: 그래픽 품질보다 위치, 방향, 시간과 판정 설명의 일관성을 우선한다.
- 단일 원본: 모든 편집 화면은 하나의 문서 상태를 사용한다.
- 비파괴 편집: 가져온 데이터와 로컬 게임 원본을 직접 변경하지 않는다.
- 오프라인 우선: 인터넷이 없어도 편집, 저장, 미리보기와 렌더링이 가능하다.
- 점진적 정밀화: 교육용 기본 판정과 실제 DSR 검증값을 분리해 나중에 교정할 수 있게 한다.
- 대체 가능 자산: 실제 게임 자산이 없어도 플레이스홀더로 모든 기능을 사용할 수 있다.

## 범위 밖

- DARK SOULS REMASTERED의 온라인 서버나 PvP 네트워크 프로토콜 구현
- 게임 프로세스 메모리 조작, 실시간 후킹 또는 치트 기능
- 게임 파일 수정과 모드 설치
- 범용 3D 모델러·리거·비선형 영상 편집기의 모든 기능
- 게임 원본 자산을 포함한 재배포
- 여러 사용자의 실시간 공동 편집과 클라우드 계정
